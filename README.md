# HunterFlow

Add-on für Jäger in WoW Forever. Es hilft beim Kiten mit einer Auto-Shot-Leiste und befindet sich noch im Test.

## Installieren und aktualisieren

1. Lade `HunterFlow-Update.bat` aus dem [neuesten Release](https://github.com/GamerVibes/HunterFlow/releases/latest) herunter.
2. Starte die Datei mit einem Doppelklick. Windows warnt eventuell, weil sie nicht signiert ist. Dann auf "Weitere Informationen" und "Trotzdem ausführen" klicken.
3. Für jedes Update die Datei einfach wieder starten. Sie sagt dir, ob `/reload` reicht oder WoW neu gestartet werden muss.

Deine Einstellungen bleiben dabei erhalten.

## Fehler melden

Lua-Fehler stehen in `World of Warcraft\_forever_\Logs\General.log`. Schick diese Datei mit einer kurzen Beschreibung an Marvin.
